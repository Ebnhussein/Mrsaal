١. حمّل إضافة التجربة

تحميل إضافة التجربة ZIP
  1. فك ضغط الملف، وافتح chrome://extensions أو edge://extensions.
  2. فعّل Developer mode، واضغط Load unpacked واختار المجلد المستخرج.
  3. سيب الصفحة دي مفتوحة. من الإضافة، اضغط «ربط حساب مرسال». الحساب هيظهر trial@mrsaal.test.
  4. افتح Maps أو صفحة نتائج، واضغط أيقونة الإضافة عليها، ثم «ابدأ الجمع والإضافة لحسابي».
نسخة التجربة متصلة بهذه الصفحة المحلية فقط. التقديم والإرسال غير متاحين في البيئة دي.
