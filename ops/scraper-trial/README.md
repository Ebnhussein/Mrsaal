# تجربة Mrsaal Scraper بشكل منفصل

الفرع ده للتجربة فقط. لا يحتاج دمج `main` أو ربط قاعدة بيانات الموقع الأساسي.

## تشغيل محلي

نزّل نسخة منفصلة من فرع التجربة، ثم شغّلها:

```bash
git clone --branch feat/browser-company-import --single-branch https://github.com/Ebnhussein/Mrsaal.git mrsaal-trial
cd mrsaal-trial
npm ci
npm run trial:scraper
```

افتح `http://localhost:4174/app` على نفس الكمبيوتر. الصفحة بتنشئ حساب تجربة
محلي `trial@mrsaal.test`، وبتعرض الشركات والوظائف اللي تجمعها.
اضغط **تحميل إضافة التجربة ZIP** واتبع تعليمات Load unpacked الموجودة بالصفحة.
الملف ده مربوط بعنوان التجربة المحلية فقط، ولا يملك صلاحية الوصول لموقع مرسال
الأساسي. سيب الصفحة مفتوحة أثناء الاختبار.

خطوات التجربة:

1. اربط الإضافة وتأكد أن الحساب المعروض هو `trial@mrsaal.test`.
2. افتح Maps وابحث عن مجال ومدينة، ثم اضغط أيقونة الإضافة على الصفحة.
3. ابدأ الجمع، ثم حدّث النتائج في صفحة التجربة.
4. كرر نفس الاستيراد وتأكد أن الشركات لا تتكرر.
5. جرّب جدول شركات أو صفحة وظائف تدعم JobPosting، وراجع الوظائف المحفوظة.
6. جرّب إيقاف الجمع وتغيير اللغة وحدود الدفعة.

لإيقاف التجربة اضغط Ctrl+C. البيانات محفوظة محليًا داخل `.mrsaal-trial`؛ إعادة
التشغيل تحافظ عليها. لا تستخدم بيانات خاصة أو مفاتيح إنتاج في الاختبار.

## العزل

- الخادم يستمع على `127.0.0.1` فقط، مع التحقق من عنوان localhost وOrigin.
- PostgreSQL مدمج ومنفصل، ولا تُقرأ إعدادات اتصال قاعدة الإنتاج أو `.env`.
- الحساب والجلسة تجريبيان. النظام الأساسي وSupabase وGoogle OAuth غير مطلوبين.
- لا يتم تحميل مسارات الإرسال أو عمال الحملات أو تكاملات واتساب/الإيميل.
- لا يوجد إرسال أو تقديم فعلي في البيئة دي.

هذا رابط محلي يعمل بعد تشغيل الأمر، وليس رابط staging منشورًا على الإنترنت.
لنشر بيئة مشتركة لاحقًا، استخدم نسخة مستقلة من الباك إند الأصلي بقاعدة بيانات
وحسابات اختبار مستقلة وحماية دخول، ثم ابنِ الإضافة لأصل HTTPS الخاص بها:

```bash
npm run build:scraper -- --origin https://YOUR-STAGING-DOMAIN --out ./scraper-staging
```

الأمر يخرج مجلد إضافة وملف ZIP. لا يغير ملفات الإضافة الأساسية، ولا ينشر أي شيء.

## تحديث الإضافة بعد `git pull`

1. أوقف أمر التجربة بـCtrl+C، ثم شغّل `git pull` و`npm run trial:scraper`.
2. حدّث صفحة التجربة وافتح تنزيل ZIP من جديد؛ لازم تحمل الملفات الجديدة.
3. فك الضغط واستبدل ملفات مجلد الإضافة القديم، ثم اضغط Reload من صفحة إضافات
   Chrome/Edge. لو اخترت مجلدًا جديدًا، احذف الإضافة القديمة وحمّل الجديد.
4. تأكد أن النسخة المعروضة في صفحة الإضافات هي `0.2.0`، وحدّث تبويب Maps
   قبل إعادة الجمع. التحميل التلقائي مفعل افتراضيًا في النسخة الجديدة.

بيانات التجربة المحفوظة لا تتغير عند تحديث كود الإضافة.
