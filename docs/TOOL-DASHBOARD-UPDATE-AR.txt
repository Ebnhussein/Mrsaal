تحديث مرسال — تصميم التول والداشبورد + الإنجليزية + الدارك مود

طريقة الرفع:
1. فك ضغط الملف على جهازك.
2. داخل مستودع GitHub الحالي، ارفع الملفات الموجودة في التحديث إلى نفس المسارات، واستبدل الملفات القديمة عند تطابق الاسم. لا تمسح بقية المشروع.
3. مهم: أضف الملفات الجديدة الأربعة في public/assets أيضًا، خصوصًا workspace-translations.json. بدون ملف الترجمة ستعود الواجهة إلى العربية.
4. اعمل Commit ثم Redeploy في Coolify. لو النشر التلقائي فعّال، انتظر اكتماله.
5. افتح /app و /admin واعمل تحديثًا قويًا للصفحة (Ctrl+Shift+R). يظهر زر EN/عربي للتبديل. اختيار المظهر الحالي يدعم الفاتح والداكن والنظام، ويحفظ الاختيار على الجهاز.

لا يلزم تعديل server.js أو package.json أو متغيرات Coolify أو قاعدة البيانات لهذا التحديث.
صفحة الإدارة تتطلب الحساب المصرح له بالإدارة؛ لم يتم تغيير صلاحيات الدخول.

ما تغير:
- تطبيق تصميم Stitch على صفحات الشركات والإرسال والتقارير والـCV والإعدادات وإدارة المستخدمين والدعم.
- قائمة جانبية للديسكتوب وتنقل سفلي وكروت شركات للموبايل.
- الإنجليزية مع LTR، والعربية مع RTL، بما يشمل أدلة المنتج والتور ومحتوى مساعدة المستخدم.
- لغة الواجهة لا تغيّر نصوص المستخدمين أو لغة كتابة الرسائل.
- تأكيد واضح لتعليق الحساب أو إعادة تفعيله، مع سبب اختياري وحماية من تأكيد الإجراء بالخطأ.
- البيانات والأرقام من المشروع الفعلي؛ لم تُضف مؤشرات وهمية أو خصائص غير منفذة.
